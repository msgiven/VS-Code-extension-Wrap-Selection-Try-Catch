## Общее описание проекта

Проект представляет собой расширение (плагин) для Visual Studio Code, предназначенное для автоматического оборачивания выделенного фрагмента кода в конструкцию `try...catch`. В рамках проекта реализована команда, которая обрабатывает отступы, нормализует выделенный текст и корректно сдвигает строки внутрь блока `try`, что обеспечивает чистоту и читаемость кода после рефакторинга.

### Функция `WrapSelectionInTryCatch(editor)`
- Назначение: оборачивает выделенный фрагмент кода в конструкцию `try { ... } catch(const std::exception& e) { std::cerr << "Error: " << e.what() << '\n'; }` с автоматической корректировкой отступов.
- Параметры: editor (vscode.TextEditor) — активный текстовый редактор, в котором находится выделение.
- Возвращаемое значение: Promise<void> — асинхронная операция, модифицирующая документ. В случае отсутствия выделения или активного редактора выводит сообщение об ошибке.

#### Пример использования

Исходный выделенный код:
```C++
std::cout<<"Hello world\n";
```

Код после выполнения команды:
```C++
try {
    std::cout<<"Hello world\n";
} catch(const std::exception& e) {
    std::cerr << "Error: " << e.what() << '\n';
}
```
